# reconcileWorkflowSubmission

Attach a recovered transaction hash after verifying the saved submission intent.

## Import

```ts
import { reconcileWorkflowSubmission } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { reconcileWorkflowSubmission } from "@ensforge/core";
import { config } from "./config";

type Input = Parameters<typeof reconcileWorkflowSubmission>[1];
declare const parameters: Input;

const result = await reconcileWorkflowSubmission(config, parameters);
```

## Parameters

```ts
type Input = Parameters<typeof reconcileWorkflowSubmission>[1];
```

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### workflowId

`string`

Existing saved workflow instance ID.

### submissionId

`string`

Submission key from getWorkflow().submissions.

### transactionHash

`` `0x${string}` ``

Recovered on-chain transaction hash to verify.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof reconcileWorkflowSubmission>>;
```

## Error

<ErrorGuide />

Deployment, account and authorization mismatches remain explicit errors. Reconcile uncertain submissions before retrying a write.
