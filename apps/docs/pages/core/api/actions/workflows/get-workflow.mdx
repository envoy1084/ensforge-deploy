# getWorkflow

Read saved workflow progress and submission references.

## Import

```ts
import { getWorkflow } from "@ensforge/core";
```

## Usage

:::code-group

```ts [index.ts]
import { getWorkflow } from "@ensforge/core";
import { config } from "./config";

type Input = Parameters<typeof getWorkflow>[1];
declare const parameters: Input;

const result = await getWorkflow(config, parameters);
```

// [!include ~/snippets/hca/config.ts]

:::

## Parameters

```ts
type Input = Parameters<typeof getWorkflow>[1];
```

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### workflowId

`string`

Existing saved workflow instance ID.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof getWorkflow>>;
```

Returns `WorkflowSnapshot`.

import { Effect } from "effect";

<ErrorGuide />

Deployment, account and authorization mismatches remain explicit errors. Reconcile uncertain submissions before retrying a write.
