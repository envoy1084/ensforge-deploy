# upgradeHca

Perform an owner-authorized gated upgrade.

## Import

```ts
import { upgradeHca } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { upgradeHca } from "@ensforge/core/hca";
import { config } from "./config";

const result = await upgradeHca(config, {
  hca: "0x1234567890123456789012345678901234567890",
  implementation: "0x5678901234567890123456789012345678901234",
});
```

## Parameters

```ts
import type { HcaManagementParameters } from "@ensforge/core/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### confirmation

`ConfirmationPolicy | undefined`

Receipt confirmation policy.

### walletClient

`WalletClient | undefined`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### data

`` `0x${string}` | undefined ``

Encoded initialization or operation data.

## Return Type

```ts
import type { HcaManagementResult } from "@ensforge/core/hca";
```

| Property  | Type                         | Description                                    |
| --------- | ---------------------------- | ---------------------------------------------- |
| `hash`    | `` `0x${string}` ``          | Submitted transaction hash.                    |
| `receipt` | `TransactionReceipt \| null` | Confirmed transaction receipt, when requested. |
