# getAuthorizedHcaOwner

Resolve the authorized owner through the account interface.

## Import

```ts
import { getAuthorizedHcaOwner } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { getAuthorizedHcaOwner } from "@ensforge/core/hca";
import { config } from "./config";

const result = await getAuthorizedHcaOwner(config, {
  hca: "0x1234567890123456789012345678901234567890",
});
```

## Parameters

```ts
import type { HcaReadParameters } from "@ensforge/core/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type GetAuthorizedHcaOwnerResult = Awaited<ReturnType<typeof getAuthorizedHcaOwner>>;
```

Returns `` `0x${string}` | null ``.
