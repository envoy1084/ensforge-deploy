# getAuthorizedHcaOwner

Resolve the authorized owner through the account interface.

## Import

```ts
import { getAuthorizedHcaOwner } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { getAuthorizedHcaOwner } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof getAuthorizedHcaOwner>[1];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
};

const result = await getAuthorizedHcaOwner(config, parameters);
```


## Parameters

```ts
type Input = Parameters<typeof getAuthorizedHcaOwner>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof getAuthorizedHcaOwner>>;
```

Returns `` `0x${string}` | null ``.
