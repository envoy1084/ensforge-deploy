# getHcaExecutionStatus

Reconcile a tracking reference.

## Import

```ts
import { getHcaExecutionStatus } from "@ensforge/core/hca";
```

## Parameters

```ts
type Input = Parameters<typeof getHcaExecutionStatus>[1];
```

### submission

`HcaExecutionSubmission<unknown>`

Previously returned or explicitly recovered execution submission.

### execution

`ExecutionAdapter<unknown, unknown, unknown> | undefined`

Compatible execution adapter. Omit for direct owner execution when supported.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof getHcaExecutionStatus>>;
```

Returns `HcaExecutionStatus`.

## Error

<ErrorGuide />

Deployment, account and authorization mismatches remain explicit errors. Reconcile uncertain submissions before retrying a write.
