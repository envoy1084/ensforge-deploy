# getHcaUpgradeEligibility

Check the candidate implementation and both upgrade gates.

## Import

```ts
import { getHcaUpgradeEligibility } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { getHcaUpgradeEligibility } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof getHcaUpgradeEligibility>[1];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
  implementation: "0x0000000000000000000000000000000000000001",
};

const result = await getHcaUpgradeEligibility(config, parameters);
```

## Parameters

```ts
type Input = Parameters<typeof getHcaUpgradeEligibility>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.
