# getHca

Inspect the account and deployment state.

## Import

```ts
import { getHca } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { getHca } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof getHca>[1];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
};

const result = await getHca(config, parameters);
```

## Parameters

```ts
type Input = Parameters<typeof getHca>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof getHca>>;
```

Returns `HcaState`.
