# predictHcaAddress

Predict the deterministic account address.

## Import

```ts
import { predictHcaAddress } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { predictHcaAddress } from "@ensforge/core/hca";
import { config } from "./config";

const result = await predictHcaAddress(config, {
  owner: "0x2345678901234567890123456789012345678901",
});
```

## Parameters

```ts
import type { HcaDerivationParameters } from "@ensforge/core/hca";
```

### owner

`` `0x${string}` ``

Owner address used for account derivation or authorization.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### implementation

`` `0x${string}` | undefined ``

Implementation address to inspect, approve or use for derivation.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type PredictHcaAddressResult = Awaited<ReturnType<typeof predictHcaAddress>>;
```
