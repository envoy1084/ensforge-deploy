# withdrawHcaDeposit

Use the validated owner self-call withdrawal route.

## Import

```ts
import { withdrawHcaDeposit } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]

type Input = Parameters<typeof withdrawHcaDeposit>[1];
```

## Parameters

```ts
type Input = Parameters<typeof withdrawHcaDeposit>[1];
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### amount

`bigint`

Native token amount in wei.

### to

`` `0x${string}` ``

Destination address.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof withdrawHcaDeposit>>;
```
