# isHcaImplementationTrusted

Check trusted implementation membership.

## Import

```ts
import { isHcaImplementationTrusted } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { isHcaImplementationTrusted } from "@ensforge/core/hca";
import { config } from "./config";

const result = await isHcaImplementationTrusted(config, {
  implementation: "0x5678901234567890123456789012345678901234",
});
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

## Parameters

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type IsHcaImplementationTrustedResult = Awaited<ReturnType<typeof isHcaImplementationTrusted>>;
```

Returns `boolean`.
