# isHcaImplementationTrusted

Check trusted implementation membership.

## Import

```ts
import { isHcaImplementationTrusted } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { isHcaImplementationTrusted } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof isHcaImplementationTrusted>[1];
const parameters: Input = {
  implementation: "0x0000000000000000000000000000000000000001",
};

const result = await isHcaImplementationTrusted(config, parameters);
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

## Parameters

```ts
type Input = Parameters<typeof isHcaImplementationTrusted>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof isHcaImplementationTrusted>>;
```

Returns `boolean`.
