# getHcaNonce

Read an EntryPoint nonce for a nonce key.

## Import

```ts
import { getHcaNonce } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { getHcaNonce } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof getHcaNonce>[1];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
  key: 0n,
};

const result = await getHcaNonce(config, parameters);
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

## Parameters

```ts
type Input = Parameters<typeof getHcaNonce>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### key

`bigint`

EntryPoint nonce key.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof getHcaNonce>>;
```

Returns `bigint`.
