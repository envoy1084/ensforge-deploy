# supportsHcaExecutionMode

Check an execution mode.

## Import

```ts
import { supportsHcaExecutionMode } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]

type Input = Parameters<typeof supportsHcaExecutionMode>[1];

const result = await supportsHcaExecutionMode(config, parameters);
```

## Parameters

```ts
type Input = Parameters<typeof supportsHcaExecutionMode>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### mode

`` `0x${string}` ``

Encoded execution mode to check.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof supportsHcaExecutionMode>>;
```

Returns `boolean`.
