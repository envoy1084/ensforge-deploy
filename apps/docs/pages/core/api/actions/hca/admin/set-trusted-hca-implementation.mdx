# setTrustedHcaImplementation

Update trusted implementation membership.

## Import

```ts
import { setTrustedHcaImplementation } from "@ensforge/core/hca/admin";
```

## Usage

:::code-group

```ts [index.ts]
import { setTrustedHcaImplementation } from "@ensforge/core/hca/admin";
import { config } from "./config";

type Input = Parameters<typeof setTrustedHcaImplementation>[1];
declare const parameters: Input;

const result = await setTrustedHcaImplementation(config, parameters);
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
type Input = Parameters<typeof setTrustedHcaImplementation>[1];
```

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### approved

`boolean`

Whether to approve the selected implementation.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof setTrustedHcaImplementation>>;
```

Returns `HcaManagementResult`.

## Error

<ErrorGuide />
