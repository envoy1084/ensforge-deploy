# revokeTrustedHcaRoles

Revoke resource roles on a trusted HCA set.

## Import

```ts
import { revokeTrustedHcaRoles } from "@ensforge/core/hca/admin";
```

## Usage

:::code-group

```ts [index.ts]
import { revokeTrustedHcaRoles } from "@ensforge/core/hca/admin";
import { config } from "./config";

const result = await revokeTrustedHcaRoles(config, {
  assignee: "0x2345678901234567890123456789012345678901",
  roles: 1n,
});
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
import type { HcaAdminWriteParameters } from "@ensforge/core/hca/admin";
```

### assignee

`` `0x${string}` ``

Address whose resource roles are read, granted or revoked.

### roles

`bigint`

Role bitmask to read, grant or revoke.

### confirmation

`ConfirmationPolicy | undefined`

Receipt confirmation policy.

### walletClient

`WalletClient | undefined`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### resource

`bigint | undefined`

Resource identifier for the role operation.

import type { HcaManagementResult } from "@ensforge/core/hca";
