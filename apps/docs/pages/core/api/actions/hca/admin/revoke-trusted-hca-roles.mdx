# revokeTrustedHcaRoles

Revoke resource roles on a trusted HCA set.

## Import

```ts
import { revokeTrustedHcaRoles } from "@ensforge/core/hca/admin";
```

## Usage

:::code-group

```ts [index.ts]
import { revokeTrustedHcaRoles } from "@ensforge/core/hca/admin";
import { config } from "./config";

type Input = Parameters<typeof revokeTrustedHcaRoles>[1];
declare const parameters: Input;

const result = await revokeTrustedHcaRoles(config, parameters);
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
type Input = Parameters<typeof revokeTrustedHcaRoles>[1];
```

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### assignee

`` `0x${string}` ``

Address whose resource roles are read, granted or revoked.

### roles

`bigint`

Role bitmask to read, grant or revoke.

### resource

`bigint | undefined`

Resource identifier for the role operation.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof revokeTrustedHcaRoles>>;
```

Returns `HcaManagementResult`.
