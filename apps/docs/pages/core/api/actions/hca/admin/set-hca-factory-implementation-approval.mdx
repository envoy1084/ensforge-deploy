# setHcaFactoryImplementationApproval

Set an implementation approval on the HCA factory.

## Import

```ts
import { setHcaFactoryImplementationApproval } from "@ensforge/core/hca/admin";
```

## Usage

:::code-group

```ts [index.ts]
import { setHcaFactoryImplementationApproval } from "@ensforge/core/hca/admin";
import { config } from "./config";

const result = await setHcaFactoryImplementationApproval(config, {
  implementation: "0x5678901234567890123456789012345678901234",
  approved: true,
});
```

```ts [config.ts]
// [!include ~/snippets/hca/config.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
import type { HcaAdminWriteParameters } from "@ensforge/core/hca/admin";
```

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### approved

`boolean`

Whether to approve the selected implementation.

### confirmation

`ConfirmationPolicy | undefined`

Receipt confirmation policy.

### walletClient

`WalletClient | undefined`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.
