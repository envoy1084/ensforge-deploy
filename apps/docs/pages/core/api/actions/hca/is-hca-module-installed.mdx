# isHcaModuleInstalled

Check a module type/address.

## Import

```ts
import { isHcaModuleInstalled } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { isHcaModuleInstalled } from "@ensforge/core/hca";
import { config } from "./config";

const result = await isHcaModuleInstalled(config, {
  hca: "0x1234567890123456789012345678901234567890",
  moduleTypeId: 1n,
  module: "0x5678901234567890123456789012345678901234",
});
```

## Parameters

```ts
import type { HcaReadParameters } from "@ensforge/core/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### moduleTypeId

`bigint`

ERC-7579 module type identifier.

### module

`` `0x${string}` ``

Module contract address.

### additionalContext

`` `0x${string}` | undefined ``

Module-specific inspection context.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type IsHcaModuleInstalledResult = Awaited<ReturnType<typeof isHcaModuleInstalled>>;
```

Returns `boolean`.
