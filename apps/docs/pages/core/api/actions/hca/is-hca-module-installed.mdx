# isHcaModuleInstalled

Check a module type/address.

## Import

```ts
import { isHcaModuleInstalled } from "@ensforge/core/hca";
```

## Usage

:::code-group

```ts [index.ts]
import { isHcaModuleInstalled } from "@ensforge/core/hca";
import { config } from "./config";

type Input = Parameters<typeof isHcaModuleInstalled>[1];
declare const parameters: Input;

const result = await isHcaModuleInstalled(config, parameters);
```

## Parameters

```ts
type Input = Parameters<typeof isHcaModuleInstalled>[1];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### moduleTypeId

`bigint`

ERC-7579 module type identifier.

### module

`` `0x${string}` ``

Module contract address.

### additionalContext

`` `0x${string}` | undefined ``

Module-specific inspection context.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof isHcaModuleInstalled>>;
```

Returns `boolean`.
