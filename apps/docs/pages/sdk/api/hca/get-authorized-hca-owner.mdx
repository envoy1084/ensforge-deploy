# getAuthorizedHcaOwner

Resolve the authorized owner through the account interface.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.getAuthorizedHcaOwner>[0];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
};

const result = await sdk.hca.getAuthorizedHcaOwner(parameters);
```

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.getAuthorizedHcaOwner>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.
