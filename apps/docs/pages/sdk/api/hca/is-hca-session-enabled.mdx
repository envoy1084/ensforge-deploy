# isHcaSessionEnabled

Check a permission ID on the destination validator.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.isHcaSessionEnabled>[0];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
  permissionId: "0x0101010101010101010101010101010101010101010101010101010101010101",
};

const result = await sdk.hca.isHcaSessionEnabled(parameters);
```

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.isHcaSessionEnabled>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### permissionId

`` `0x${string}` ``

Permission identifier of the prepared or enabled session.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.isHcaSessionEnabled>>;
```

Returns `boolean`.
