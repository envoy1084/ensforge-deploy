# getHcaUpgradeEligibility

Check the candidate implementation and both upgrade gates.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage


## Parameters

```ts
type Input = Parameters<typeof sdk.hca.getHcaUpgradeEligibility>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.
