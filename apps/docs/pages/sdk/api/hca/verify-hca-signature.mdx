# verifyHcaSignature

Validate a signature; RPC failures remain errors.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.verifyHcaSignature>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### hash

`` `0x${string}` ``

Digest to inspect or verify.

### signature

`` `0x${string}` ``

Encoded signature to validate.

### sender

`` `0x${string}` | undefined ``

Caller address used during signature verification.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.verifyHcaSignature>>;
```

Returns `boolean`.
