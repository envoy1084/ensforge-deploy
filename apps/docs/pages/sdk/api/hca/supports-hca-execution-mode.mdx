# supportsHcaExecutionMode

Check an execution mode.


## Parameters

```ts
type Input = Parameters<typeof sdk.hca.supportsHcaExecutionMode>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### mode

`` `0x${string}` ``

Encoded execution mode to check.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.supportsHcaExecutionMode>>;
```
