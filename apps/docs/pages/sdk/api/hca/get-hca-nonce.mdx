# getHcaNonce

Read an EntryPoint nonce for a nonce key.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

const result = await sdk.hca.getHcaNonce({
  hca: "0x1234567890123456789012345678901234567890",
  key: 0n,
});
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

## Parameters

```ts
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### key

`bigint`

EntryPoint nonce key.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type GetHcaNonceResult = Awaited<ReturnType<typeof sdk.hca.getHcaNonce>>;
```

Returns `bigint`.
