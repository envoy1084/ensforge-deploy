# getHcaNonce

Read an EntryPoint nonce for a nonce key.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.getHcaNonce>[0];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
  key: 0n,
};

const result = await sdk.hca.getHcaNonce(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.getHcaNonce>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### key

`bigint`

EntryPoint nonce key.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.getHcaNonce>>;
```

Returns `bigint`.
