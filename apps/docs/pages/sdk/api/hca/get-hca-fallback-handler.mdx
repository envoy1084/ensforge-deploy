# getHcaFallbackHandler

Inspect the handler for a selector.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.getHcaFallbackHandler>[0];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
  selector: "0x00000000",
};

const result = await sdk.hca.getHcaFallbackHandler(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.getHcaFallbackHandler>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### selector

`` `0x${string}` ``

Function selector whose fallback handler is inspected.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.getHcaFallbackHandler>>;
```

Returns ``{ readonly callType: `0x${string}`; readonly handler: `0x${string}`; }``.
