# getHcaExecutors

Inspect executors with pagination.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.getHcaExecutors>[0];
const parameters: Input = {
  hca: "0x0000000000000000000000000000000000000001",
};

const result = await sdk.hca.getHcaExecutors(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.getHcaExecutors>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### cursor

`` `0x${string}` | undefined ``

Starting address for module pagination.

### size

`bigint | undefined`

Maximum number of module entries to return.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.getHcaExecutors>>;
```

Returns `HcaModulePage`.
