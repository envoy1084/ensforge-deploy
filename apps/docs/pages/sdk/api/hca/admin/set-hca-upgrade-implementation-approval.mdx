# setHcaUpgradeImplementationApproval

Set a directional implementation approval on the upgrade gate.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.admin.setHcaUpgradeImplementationApproval>[0];
declare const parameters: Input;

const result = await sdk.hca.admin.setHcaUpgradeImplementationApproval(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.admin.setHcaUpgradeImplementationApproval>[0];
```

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### approved

`boolean`

Whether to approve the selected implementation.

### gate

`` `0x${string}` | undefined ``

Optional upgrade-gate address. Defaults to the deployment profile gate.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.admin.setHcaUpgradeImplementationApproval>>;
```
