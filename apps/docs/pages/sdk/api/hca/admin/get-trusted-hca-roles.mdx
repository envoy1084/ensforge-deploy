# getTrustedHcaRoles

Read resource roles on a trusted HCA set.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.admin.getTrustedHcaRoles>[0];
declare const parameters: Input;

const result = await sdk.hca.admin.getTrustedHcaRoles(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.admin.getTrustedHcaRoles>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### assignee

`` `0x${string}` ``

Address whose resource roles are read, granted or revoked.

### resource

`bigint | undefined`

Resource identifier for the role operation.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.admin.getTrustedHcaRoles>>;
```
