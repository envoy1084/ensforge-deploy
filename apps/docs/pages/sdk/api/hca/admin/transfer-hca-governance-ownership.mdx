# transferHcaGovernanceOwnership

Transfer ownership of a supported HCA governance contract.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

type Input = Parameters<typeof sdk.hca.admin.transferHcaGovernanceOwnership>[0];
declare const parameters: Input;

const result = await sdk.hca.admin.transferHcaGovernanceOwnership(parameters);
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

This targets HCA governance contracts. It does not transfer or renounce the immutable account owner.

## Parameters

```ts
type Input = Parameters<typeof sdk.hca.admin.transferHcaGovernanceOwnership>[0];
```

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### target

`HcaGovernanceTarget`

Governance contract to inspect or modify.

### newOwner

`` `0x${string}` ``

New governance owner; this does not change the immutable HCA owner.

## Return Type

```ts
type Result = Awaited<ReturnType<typeof sdk.hca.admin.transferHcaGovernanceOwnership>>;
```
