Read the EntryPoint address.


## Parameters

```ts
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type GetHcaEntryPointResult = Awaited<ReturnType<typeof sdk.hca.getHcaEntryPoint>>;
```

Returns `` `0x${string}` ``.
