# isHcaModuleInstalled

Check a module type/address.

## Import

```ts
import { Ensforge } from "@ensforge/sdk";
```

## Usage

:::code-group

```ts [index.ts]
import { sdk } from "./client";

const result = await sdk.hca.isHcaModuleInstalled({
  hca: "0x1234567890123456789012345678901234567890",
  moduleTypeId: 1n,
  module: "0x5678901234567890123456789012345678901234",
});
```

```ts [client.ts]
// [!include ~/snippets/hca/client.ts]
```

:::

## Parameters

```ts
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### moduleTypeId

`bigint`

ERC-7579 module type identifier.

### module

`` `0x${string}` ``

Module contract address.

### additionalContext

`` `0x${string}` | undefined ``

Module-specific inspection context.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

## Return Type

```ts
type IsHcaModuleInstalledResult = Awaited<ReturnType<typeof sdk.hca.isHcaModuleInstalled>>;
```

Returns `boolean`.
