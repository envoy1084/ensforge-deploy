# Installation

:::code-group

```sh [pnpm]
pnpm add @ensforge/sdk effect@^4 viem
```

```sh [npm]
npm install @ensforge/sdk effect@^4 viem
```

```sh [yarn]
yarn add @ensforge/sdk effect@^4 viem
```

```sh [bun]
bun add @ensforge/sdk effect@^4 viem
```

:::

Install `wagmi` as well when you plan to construct the SDK from a Wagmi config. Wagmi 2.19 and 3.x
are supported.

```sh
pnpm add wagmi
```

The package is ESM-only and includes TypeScript declarations.
