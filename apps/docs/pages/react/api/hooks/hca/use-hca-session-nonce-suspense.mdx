# useHcaSessionNonceSuspense

Read the session revocation nonce Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaSessionNonceSuspense } from "@ensforge/react";
```

:::code-group

```tsx [component.tsx]
import { useHcaSessionNonceSuspense } from "@ensforge/react";
```

## Parameters

```ts
type Input = Parameters<typeof useHcaSessionNonceSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.
