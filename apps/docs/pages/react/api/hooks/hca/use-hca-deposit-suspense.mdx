# useHcaDepositSuspense

Read the EntryPoint deposit balance Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaDepositSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaDepositSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaDepositSuspense>[0]) {
  const result = useHcaDepositSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaDepositSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.
