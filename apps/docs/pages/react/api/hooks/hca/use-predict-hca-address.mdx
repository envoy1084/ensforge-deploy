# usePredictHcaAddress

Predict the deterministic account address Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { usePredictHcaAddress } from "@ensforge/react";
```

## Parameters

```ts
type Input = Parameters<typeof usePredictHcaAddress>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### owner

`` `0x${string}` ``

Owner address used for account derivation or authorization.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### implementation

`` `0x${string}` | undefined ``

Implementation address to inspect, approve or use for derivation.
