# useHcaSigningDomain

Read the account signing domain Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaSigningDomain } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaSigningDomain } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaSigningDomain>[0]) {
  const result = useHcaSigningDomain(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaSigningDomain>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.
