# useHcaSuspense

Inspect the account and deployment state Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaSuspense>[0]) {
  const result = useHcaSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.
