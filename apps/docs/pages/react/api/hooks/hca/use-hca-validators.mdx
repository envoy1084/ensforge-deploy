# useHcaValidators

Inspect validators with pagination Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaValidators } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaValidators } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaValidators>[0]) {
  const result = useHcaValidators(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaValidators>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### cursor

`` `0x${string}` | undefined ``

Starting address for module pagination.

### size

`bigint | undefined`

Maximum number of module entries to return.
