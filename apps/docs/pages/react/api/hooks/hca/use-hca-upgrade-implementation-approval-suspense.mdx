# useHcaUpgradeImplementationApprovalSuspense

Read directional upgrade approval Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaUpgradeImplementationApprovalSuspense } from "@ensforge/react";
```

## Parameters

```ts
type Input = Parameters<typeof useHcaUpgradeImplementationApprovalSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### gate

`` `0x${string}` | undefined ``

Optional upgrade-gate address. Defaults to the deployment profile gate.
