# useHcaValidatorsSuspense

Inspect validators with pagination. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaValidatorsSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaValidatorsSuspense } from "@ensforge/react";

function Component() {
  const result = useHcaValidatorsSuspense({
    hca: "0x1234567890123456789012345678901234567890",
  });

  return (
    <pre>
      {JSON.stringify(
        result.data,
        (_, value) => (typeof value === "bigint" ? value.toString() : value),
        2,
      )}
    </pre>
  );
}
```

## Parameters

```ts
import type { UseEnsSuspenseAtomParameters } from "@ensforge/react";
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### cursor

`` `0x${string}` | undefined ``

Starting address for module pagination.

### size

`bigint | undefined`

Maximum number of module entries to return.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.
