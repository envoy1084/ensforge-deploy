# useAuthorizedHcaOwnerSuspense

Resolve the authorized owner through the account interface. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useAuthorizedHcaOwnerSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useAuthorizedHcaOwnerSuspense } from "@ensforge/react";

function Component() {
  const result = useAuthorizedHcaOwnerSuspense({
    hca: "0x1234567890123456789012345678901234567890",
  });

  return (
    <pre>
      {JSON.stringify(
        result.data,
        (_, value) => (typeof value === "bigint" ? value.toString() : value),
        2,
      )}
    </pre>
  );
}
```

## Parameters

```ts
import type { UseEnsSuspenseAtomParameters } from "@ensforge/react";
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.
