# useExecuteHcaCalls

Execute through the owner wallet or supplied adapter Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useExecuteHcaCalls } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useExecuteHcaCalls } from "@ensforge/react";

function Component({
  parameters,
}: {
  parameters: Parameters<ReturnType<typeof useExecuteHcaCalls>["mutate"]>[0];
}) {
  const mutation = useExecuteHcaCalls();
  return (
    <button disabled={mutation.isWaiting} onClick={() => mutation.mutate(parameters)}>
      Run
    </button>
  );
}
```

```tsx [provider.tsx]
// [!include ~/snippets/hca/provider.tsx]
```

:::

## Parameters

Pass operation parameters to `mutate`, `mutateAsync` or `mutateEffect`. Hook options accept `onExit` and an explicit retry policy.

```ts
type Input = Parameters<ReturnType<typeof useExecuteHcaCalls>["mutate"]>[0];
```

### counterfactualOwner

`` `0x${string}` | undefined ``

Expected owner for counterfactual execution.

### operationId

`string | undefined`

Optional caller correlation identifier for execution tracking.

### requiredCapabilities

`readonly ("ownerExecution" | "sessionExecution" | "counterfactualDeployment" | "atomicBatching" | "sponsorship" | "crossChainFunding")[] | undefined`

Capabilities that the execution route must support.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### authorization

`HcaAuthorization`

Owner authorization or an enabled destination session.

### calls

``readonly ({ readonly to: `0x${string}`; readonly data?: `0x${string}` | undefined; readonly value?: bigint | undefined; } | EnsWriteIntent<unknown, WriteError>)[]``

Ordered raw contract calls or supported ENS .call intents.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

### execution

`Adapter | undefined`

Compatible execution adapter. Omit for direct owner execution when supported.

## Return Type

```ts
type Result = ReturnType<typeof useExecuteHcaCalls>;
```

The mutation exposes `data`, `error`, `isWaiting`, `result`, execution methods, `reset` and `interrupt`. Interruption stops local work; it does not undo a broadcast or revoke a session. See [Mutation Hooks](/react/guides/mutations).
