# useHcaExecutors

Inspect executors with pagination Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaExecutors } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaExecutors } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaExecutors>[0]) {
  const result = useHcaExecutors(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaExecutors>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### cursor

`` `0x${string}` | undefined ``

Starting address for module pagination.

### size

`bigint | undefined`

Maximum number of module entries to return.
