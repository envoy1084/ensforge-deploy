# useHcaFallbackHandlerSuspense

Inspect the handler for a selector Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaFallbackHandlerSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaFallbackHandlerSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaFallbackHandlerSuspense>[0]) {
  const result = useHcaFallbackHandlerSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaFallbackHandlerSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### selector

`` `0x${string}` ``

Function selector whose fallback handler is inspected.
