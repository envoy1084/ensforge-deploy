# useEnableHcaSession

Owner-authorize a constrained session Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useEnableHcaSession } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useEnableHcaSession } from "@ensforge/react";

function Component({
  parameters,
}: {
  parameters: Parameters<ReturnType<typeof useEnableHcaSession>["mutate"]>[0];
}) {
  const mutation = useEnableHcaSession();
  return (
    <button disabled={mutation.isWaiting} onClick={() => mutation.mutate(parameters)}>
      Run
    </button>
  );
}
```

```tsx [provider.tsx]
// [!include ~/snippets/hca/provider.tsx]
```

## Parameters

Pass operation parameters to `mutate`, `mutateAsync` or `mutateEffect`. Hook options accept `onExit` and an explicit retry policy.

```ts
type Input = Parameters<ReturnType<typeof useEnableHcaSession>["mutate"]>[0];
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### permissionId

`` `0x${string}` ``

Permission identifier of the prepared or enabled session.

### sessionKey

`` `0x${string}` ``

Address of the session signer. The private key is not passed to the action.

### validUntil

`number`

Session expiry as a Unix timestamp in seconds.

### resolver

`` `0x${string}` ``

Resolver address used by the registration or session policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

## Return Type

```ts
type Result = ReturnType<typeof useEnableHcaSession>;
```

The mutation exposes `data`, `error`, `isWaiting`, `result`, execution methods, `reset` and `interrupt`. Interruption stops local work; it does not undo a broadcast or revoke a session. See [Mutation Hooks](/react/guides/mutations).
