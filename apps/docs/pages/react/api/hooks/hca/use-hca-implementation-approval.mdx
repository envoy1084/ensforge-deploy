# useHcaImplementationApproval

Check factory implementation approval Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaImplementationApproval } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaImplementationApproval } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaImplementationApproval>[0]) {
  const result = useHcaImplementationApproval(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaImplementationApproval>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.
