# useHcaImplementationApproval

Check factory implementation approval. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaImplementationApproval } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaImplementationApproval } from "@ensforge/react";

function Component() {
  const result = useHcaImplementationApproval({
    implementation: "0x5678901234567890123456789012345678901234",
  });

  return (
    <pre>
      {JSON.stringify(
        result.data,
        (_, value) => (typeof value === "bigint" ? value.toString() : value),
        2,
      )}
    </pre>
  );
}
```

```tsx [provider.tsx]
// [!include ~/snippets/hca/provider.tsx]
```

:::

## Parameters

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.
