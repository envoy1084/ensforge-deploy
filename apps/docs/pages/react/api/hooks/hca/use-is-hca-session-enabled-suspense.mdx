# useIsHcaSessionEnabledSuspense

Check a permission ID on the destination validator Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useIsHcaSessionEnabledSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useIsHcaSessionEnabledSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useIsHcaSessionEnabledSuspense>[0]) {
  const result = useIsHcaSessionEnabledSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useIsHcaSessionEnabledSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### permissionId

`` `0x${string}` ``

Permission identifier of the prepared or enabled session.
