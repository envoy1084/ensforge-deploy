# useDeployHca

Deploy or verify the existing deterministic account Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useDeployHca } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useDeployHca } from "@ensforge/react";

function Component({
  parameters,
}: {
  parameters: Parameters<ReturnType<typeof useDeployHca>["mutate"]>[0];
}) {
  const mutation = useDeployHca();
  return (
    <button disabled={mutation.isWaiting} onClick={() => mutation.mutate(parameters)}>
      Run
    </button>
  );
}
```

```tsx [provider.tsx]
// [!include ~/snippets/hca/provider.tsx]
```

:::

## Parameters

Pass operation parameters to `mutate`, `mutateAsync` or `mutateEffect`. Hook options accept `onExit` and an explicit retry policy.

```ts
type Input = Parameters<ReturnType<typeof useDeployHca>["mutate"]>[0];
```

### owner

`` `0x${string}` ``

Owner address used for account derivation or authorization.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### implementation

`` `0x${string}` | undefined ``

Implementation address to inspect, approve or use for derivation.

### confirmation

`{ readonly type: "submitted"; } | { readonly type: "confirmed"; readonly timeout?: number | undefined; readonly confirmations?: number | undefined; }`

Receipt confirmation policy.

### walletClient

`Input["walletClient"]`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.

## Return Type

```ts
type Result = ReturnType<typeof useDeployHca>;
```

The mutation exposes `data`, `error`, `isWaiting`, `result`, execution methods, `reset` and `interrupt`. Interruption stops local work; it does not undo a broadcast or revoke a session. See [Mutation Hooks](/react/guides/mutations).
