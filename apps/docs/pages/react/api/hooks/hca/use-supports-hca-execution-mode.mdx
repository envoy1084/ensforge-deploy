# useSupportsHcaExecutionMode

Check an execution mode Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useSupportsHcaExecutionMode } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useSupportsHcaExecutionMode } from "@ensforge/react";

function Component(parameters: Parameters<typeof useSupportsHcaExecutionMode>[0]) {
  const result = useSupportsHcaExecutionMode(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

// [!include ~/snippets/hca/provider.tsx]

## Parameters

```ts
type Input = Parameters<typeof useSupportsHcaExecutionMode>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### mode

`` `0x${string}` ``

Encoded execution mode to check.
