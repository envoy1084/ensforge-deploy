# useRevokeHcaSessions

Revoke existing sessions using the account nonce. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useRevokeHcaSessions } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useRevokeHcaSessions } from "@ensforge/react";

function Component() {
  const mutation = useRevokeHcaSessions();

  return (
    <button
      disabled={mutation.isWaiting}
      onClick={() =>
        mutation.mutate({
          hca: "0x1234567890123456789012345678901234567890",
        })
      }
    >
      Revoke sessions
    </button>
  );
}
```

## Mutation Parameters

```ts
import type { RevokeHcaSessionsParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### confirmation

`ConfirmationPolicy | undefined`

Receipt confirmation policy.

### walletClient

`WalletClient | undefined`

Viem wallet override. Defaults to the configured wallet resolver.

### account

`` `0x${string}` | Account | undefined ``

Wallet account override for the operation.
