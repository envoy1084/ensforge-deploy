# useHcaCapabilitiesSuspense

Inspect supported account and execution capabilities Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaCapabilitiesSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaCapabilitiesSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaCapabilitiesSuspense>[0]) {
  const result = useHcaCapabilitiesSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaCapabilitiesSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### expectedOwner

`` `0x${string}` | undefined ``

Expected account owner. A mismatch fails verification.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### initialImplementation

`` `0x${string}` | undefined ``

Implementation used when deriving the account address, including an account that was later upgraded.

### allowUndeployed

`boolean | undefined`

Allow a counterfactual account after verifying its derivation.
