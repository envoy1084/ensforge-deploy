# useHcaUpgradeEligibilitySuspense

Check the candidate implementation and both upgrade gates. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaUpgradeEligibilitySuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaUpgradeEligibilitySuspense } from "@ensforge/react";

function Component() {
  const result = useHcaUpgradeEligibilitySuspense({
    hca: "0x1234567890123456789012345678901234567890",
    implementation: "0x5678901234567890123456789012345678901234",
  });

  return (
    <pre>
      {JSON.stringify(
        result.data,
        (_, value) => (typeof value === "bigint" ? value.toString() : value),
        2,
      )}
    </pre>
  );
}
```

## Parameters

```ts
import type { UseEnsSuspenseAtomParameters } from "@ensforge/react";
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### implementation

`` `0x${string}` ``

Implementation address to inspect, approve or use for derivation.

### salt

`bigint | undefined`

Account derivation salt. Defaults to the deployment profile canonical salt.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.
