# useHcaNonceSuspense

Read an EntryPoint nonce for a nonce key. Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaNonceSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaNonceSuspense } from "@ensforge/react";

function Component() {
  const result = useHcaNonceSuspense({
    hca: "0x1234567890123456789012345678901234567890",
    key: 0n,
  });

  return (
    <pre>
      {JSON.stringify(
        result.data,
        (_, value) => (typeof value === "bigint" ? value.toString() : value),
        2,
      )}
    </pre>
  );
}
```

## Parameters

```ts
import type { UseEnsSuspenseAtomParameters } from "@ensforge/react";
import type { HcaReadParameters } from "@ensforge/sdk/hca";
```

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### key

`bigint`

EntryPoint nonce key.

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.
