# useHcaNonceSuspense

Read an EntryPoint nonce for a nonce key Uses the SDK from `EnsforgeProvider`.

## Import

```tsx
import { useHcaNonceSuspense } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useHcaNonceSuspense } from "@ensforge/react";

function Component(parameters: Parameters<typeof useHcaNonceSuspense>[0]) {
  const result = useHcaNonceSuspense(parameters);
  return <p>{result.isWaiting ? "Loading" : "Result available"}</p>;
}
```

## Parameters

```ts
type Input = Parameters<typeof useHcaNonceSuspense>[0];
```

### blockNumber

`bigint | undefined`

Block number to read. Cannot be combined with blockTag.

### blockTag

`BlockTag | undefined`

Named block state to read. Cannot be combined with blockNumber.

### hca

`` `0x${string}` ``

HCA address to inspect or operate on.

### key

`bigint`

EntryPoint nonce key.
