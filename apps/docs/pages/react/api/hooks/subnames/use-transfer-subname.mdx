# useTransferSubname

Hook for transferring subname.

## Import

```tsx
import { useTransferSubname } from "@ensforge/react";
```

## Usage

:::code-group

```tsx [component.tsx]
import { useTransferSubname } from "@ensforge/react";

function Component() {
  const mutation = useTransferSubname();

  return (
    <button
      disabled={mutation.isWaiting}
      onClick={() =>
        mutation.mutate({
          to: "value",
          name: "example.eth",
        })
      }
    >
      Submit
    </button>
  );
}
```

## Mutation Parameters

```ts
import type { TransferSubnameParameters } from "@ensforge/sdk/subnames";
```

### unsafe

`boolean | undefined`

Defaults to `false`. For ENSv2 registry transfers, opt in to bypass the safe-transfer restrictions
on non-emancipated registries and additional role assignees. Existing roles can retain access after
an unsafe transfer; use this only when that behavior is intended.
