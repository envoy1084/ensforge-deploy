# Installation

:::code-group

```sh [pnpm]
pnpm add @ensforge/react react effect@^4 viem
```

```sh [npm]
npm install @ensforge/react react effect@^4 viem
```

```sh [yarn]
yarn add @ensforge/react react effect@^4 viem
```

```sh [bun]
bun add @ensforge/react react effect@^4 viem
```

:::

Add `wagmi` when using a Wagmi config in the provider. Wagmi 2.19 and 3.x are supported.

```sh
pnpm add wagmi
```
