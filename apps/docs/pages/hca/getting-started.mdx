# Getting Started

`@ensforge/hca` provides typed execution adapters for ENS hierarchical contract accounts. Core and
SDK own ENS actions; this package connects those actions to Pimlico or Rhinestone and exposes each
provider's extensions. There is no separate HCA client.

## Install

Follow [Installation](/hca/installation), then install the optional provider you use.

## Create an adapter

```ts
import { pimlico } from "@ensforge/hca/pimlico";

const execution = pimlico({ profile, chain, owner, client });
const submission = await sdk.hca.executeHcaCalls({
  hca,
  authorization: { kind: "owner" },
  calls,
  execution,
});
const status = await sdk.hca.waitForHcaExecution({ submission, execution });
```

See [`pimlico`](/hca/api/pimlico) for client configuration and sponsorship. Rhinestone provides
destination sessions through [`rhinestone`](/hca/api/rhinestone), with independent cross-chain funding.
